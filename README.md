#  AI Assignment & Doubt Solver

An AI-powered automation project that helps students solve academic doubts and assignment-related questions in real time using **Google Gemini AI**, **Make.com**, and a **Telegram Bot**.

This project was completed **primarily with guidance from a hands-on AI & Automation workshop by NxtWave**, focusing on building practical, real-world AI workflows.

---

##  Project Overview

The **AI Assignment & Doubt Solver** allows students to submit questions through a Telegram bot.  
The system automatically understands the question using AI and provides:

- Short and clear answers for simple factual doubts  
- Step-by-step explanations with examples for conceptual or assignment-based questions  

The entire automation is built using **a single Make.com scenario**, making it efficient, cost-effective, and easy to maintain.

---

##  Features

-  Real-time student doubt resolution  
-  AI-powered explanations using Google Gemini  
-  Fully automated workflow using Make.com  
-  Telegram-based user interaction  
-  Single-scenario architecture  

---

##  Tech Stack

- **Make.com** – Automation and workflow orchestration  
- **Google Gemini AI** – Natural language understanding and response generation  
- **Telegram Bot API** – User interaction interface  

---

##  How It Works

1. A student sends a question to the Telegram bot  
2. The message triggers a Make.com automation  
3. Google Gemini AI analyzes the question  
4. The AI generates an appropriate explanation  
5. The response is automatically sent back to the student on Telegram
